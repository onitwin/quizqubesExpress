## Environmental variables
**DB_HOST** = Route to database

**DB_USER** = Username for database

**DB_PASSWORD** = Password for database

**DB_NAME** = Name of the database

**DB_DIALECT** = Version if SQL being used

###### If using AWS or similar, the DB_NAME is the name of the database you set up, and NOT the *DB Instance ID*

###### The Dialect is the version of SQL being used e.g. *mysql*,*Postgresql*,*MariaDB* etc
